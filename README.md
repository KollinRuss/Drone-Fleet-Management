# Drone Fleet Management

A C++ application for managing a fleet of delivery drones. The project demonstrates object-oriented programming and basic fleet management functionality.

## Features

- Create and manage drone objects
- Store drone IDs and models
- Track battery life
- Track payload capacity
- Display drone information
- Manage multiple drones

## Technologies

- C++
- CMake
- Object-Oriented Programming

## How to Run

1. Clone or download this repository.
2. Open the project in CLion or another C++ IDE that supports CMake.
3. Build the project.
4. Run the program.
5. Follow the menu prompts to manage the drone fleet.

## Project Structure

- `main.cpp` - Starts the program and handles the application flow.
- `drone.cpp` - Contains the Drone class implementation.
- `drone.h` - Contains the Drone class declarations.
- `drone_utils.cpp` - Contains utility functions for the project.
- `drone_utils.h` - Contains utility function declarations.
- `CMakeLists.txt` - Configures the project build.
